## Description
Saturn Server Launcher helps you manage Minecraft servers on your Windows PC.
Choose server software, organize separate worlds, edit settings, browse server-ready
CurseForge modpacks and schedule routine hosting tasks from one interface.

Use local hosting on your network, or configure your own VPS to forward connections
without router port forwarding. Friends can join through the VPS address or your
domain. A VPS is purchased separately; your PC runs the game server and must stay
on while hosting. Shared networks must allow the outbound connection.

Features include multiple profiles, Java and Bedrock support, a file editor,
backup/restore, scheduled tasks, console-based player management and process
resource statistics. Sound effects, startup animation and volume are optional.

Minecraft, server software, runtimes and modpacks download when you request them.
Relevant upstream licenses and EULAs apply. CurseForge browsing requires your own
API key. No Minecraft license, VPS, domain or hosting subscription is included.

Saturn is an independent project, not an official Minecraft product and not
approved by or associated with Mojang or Microsoft. Created by Nova.
