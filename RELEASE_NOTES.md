# Saturn Server Launcher 1.0.2 — Optional VPS preview

- Per-profile Use VPS tunnel checkbox on Server and Settings.
- Direct LAN / router forwarding mode, without SSH or a VPS.
- Separate direct join address and router public ports; saved VPS settings remain intact.
- Java network binding follows the selected mode; scheduled starts respect the checkbox.
- Manual router/firewall instructions and direct-hosting troubleshooting.

Preview only; not published as a release.
